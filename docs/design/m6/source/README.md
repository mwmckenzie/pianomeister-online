# m6 reference sources

HTML sources of the design-canvas mockups in `docs/design/m6/`. They don't run on their own (they need the design canvas runtime), but they are the exact reference for sizes, spacing, font sizes, colours and grid columns. When a screenshot and a value here disagree, the value here wins.

- QGPicker.dc.html — song & bookmark picker (milestone 6 builds the song list, details and "Full song"; stats columns and bookmarks are milestone 7)
- QGLibrary.dc.html — library page
- QGBookmarks.dc.html — bookmark manager (milestone 7)
- QGSettings.dc.html — settings window (Audio and Appearance tabs, reset icons)
- QGPlayfield.dc.html — player with playfield sidebar

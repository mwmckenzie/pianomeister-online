## Decisions

1. **Two homes for settings.** Settings that change what you see on the playfield (camera, keyboard, highway, notes, effects, render quality) live in the **playfield sidebar**, beside the live view. Everything else lives in the **settings window** with tabs: General, Practice, Audio, Appearance, MIDI, Profiles, Library & data, Shortcuts, About. Tabs with nothing yet to show are left out until they have content (MIDI, Profiles, Shortcuts are likely empty in this milestone).
2. **Reset to default everywhere.**
   - Every setting control has a reset button: a circular-arrow icon only, with a "Reset to default" tooltip on hover and keyboard focus. It's dim when the value is at its default and in the primary color when it isn't, so changed settings are easy to spot. It never shifts the layout.
   - Every section ends with a small text button "Reset ⟨section⟩".
   - Every settings tab and the playfield sidebar end with "Reset all ⟨tab⟩ settings".
   - Section and tab resets apply at once and show a toast with **Undo** for 6 seconds (no confirm dialogs).
   - Settings tabs and sidebar sections that contain changed values show a small dot in the primary color.
3. **Menu colors.** Appearance has a **primary** color (buttons, sliders, selection, active tabs, focus rings) and a **secondary** color (charts, bar-range indicators, highlights), each with a color picker and hex value, plus presets: Glacier `#8AB4FF`/`#7EE0C3` (default), Aurora `#7EE0C3`/`#C3A6FF`, Ember `#FFB38A`/`#FFD98A`, Orchid `#D3A6FF`/`#8AB4FF`, Mono `#E8ECF6`/`#A7B0C6`. They only affect the UI, never the note palette. Ensure text on primary buttons stays readable: choose dark or light text by contrast.
4. **Glass panels:** panel opacity (default **58%**, 30–95%) and background blur (default **26 px**, 0–40). Blur 0 must still look right where `backdrop-filter` is unsupported or slow.
5. **Motion:** menu animations "Follow system" (default, respects `prefers-reduced-motion`) / Full / Reduced. Reduced = fades only, no movement.
6. **Font:** Inter Tight, **self-hosted** woff2 (weights 300/400/500/600), credited in `docs/CREDITS.md` (OFL). No runtime Google Fonts request.
7. **Tempo shown as a range** wherever a song's tempo is displayed: min–max bpm over the tempo map (single value when constant), e.g. "120–126 bpm". The player HUD keeps showing the current bpm.
8. **Song picker** opens from the player toolbar (and a shortcut, `O`). Left: song list. Middle: details of the highlighted song. Right: what to load — "Full song" pinned first, bookmarks below (milestone 7). In this milestone the right column has "Full song" only.
9. **Composer field** is a combo box: free typing with suggestions from composers already in the library, a button that lists all of them (with song counts), and "Add ‘…’ as a new composer" when nothing matches exactly.
10. **UI components:** use **Reka UI** (headless, accessible primitives) for dialog, tabs, accordion, slider, combobox, select, tooltip, toggle group and toast, styled with our own tokens. This is a new dependency (approved). No styled component framework.

## Design system

- **Tokens** as CSS custom properties in one file (`src/ui/theme/tokens.css`): colors (background, glass surface, borders, text levels from the mockups: `#E8ECF6`, `#C9D2E8`, `#A7B0C6`, `#8F9AB6`), primary/secondary and their translucent variants, type scale, spacing, radii (10/12/22), shadows, durations/easings. Theme settings write the variable values at runtime; components never hard-code colors.
- **Components** (one per file, in `src/ui/components/`): `GlassPanel`, `IconButton`, `Button` (primary / outline / text), `SegmentedControl`, `SliderField`, `ToggleField`, `SelectField`, `ComboboxField`, `ColorField`, `ResetButton`, `SettingRow`, `SettingsSection` (title + rows + section reset), `Accordion`, `TabbedWindow`, `Dialog`, `Toast`, `RangeBar` (a range inside a song, used by bookmarks later), `SortableHeader`.
- `SettingRow` takes a setting key and renders label, value, control and reset button from the registry, so a new setting is one registry entry plus one line in a section.

## Settings registry

- One declaration per setting in `core/` (pure TS): key, label, default, type and limits (min/max/step/options), unit/format, **home** (sidebar section or window tab + section). Reset groups (section, tab, sidebar) are derived from this, not listed by hand.
- Store helpers: `isDefault(key)`, `reset(key)`, `resetGroup(group)` returning the previous values for Undo, `changedCount(group)`.
- Bump the settings schema version with a migration that keeps existing values and adds the new keys (theme, glass, motion).

## Screens

1. **Player (Quiet HUD).**
   - Song title, composer and bookmark name top left.
   - Large bar:beat counter with "bar N of M · time / length".
   - Large current bpm top right, with "% of base".
   - Icon toolbar above the timeline: picker, previous bar, play/pause, next bar, loop, playfield panel.
   - Thin timeline with the loop region and a draggable playhead.
   - Replaces the temporary top-center controls. Low contrast, readable over the scene (text shadow), never covering the now line.
2. **Playfield sidebar.**
   - 360 px glass panel on the right; the highway resizes to the remaining width rather than being covered.
   - Accordion sections Camera, Keyboard, Highway, Notes, Effects, Render quality, holding all existing visual settings.
   - "All settings…" button and "Reset all playfield settings" at the bottom.
   - Open/close from the toolbar and with `P`; the open state persists.
3. **Settings window.**
   - Centered glass dialog with tabs on the left, the active tab's sections on the right, and a footer showing "N settings changed from default" plus "Reset all ⟨tab⟩ settings".
   - The nav footer links to the playfield panel.
   - Esc closes it; focus is trapped while open.
4. **Song picker.**
   - Glass dialog over the player with search.
   - **Song list** rows show the title with the composer underneath, plus a column for bookmark count (shows "—" until milestone 7).
   - **Middle:** title, composer · source; facts (length, bars, meter, tempo range); then a slot for song stats and the selected entry's stats (milestone 7: plays, practice time, last, share, 14-day bar chart).
   - **Right:** "Full song" with its full-width range bar.
   - Load / Cancel. Arrow keys move through the lists, Enter loads.
   - Leave room for sortable column headers. Sort by title or composer now; plays, time, last played and bookmarks arrive in milestone 7.
5. **Library** (restyle of the milestone 4 page).
   - Full-screen glass page with a Library tab; the Bookmarks tab arrives in milestone 7, so leave the tab bar ready.
   - Header: search, Upload MIDI, Export, Import.
   - Filters for source and tags, plus Group by; storage status.
   - Table: title with the bookmark count as subtitle (no tags in the subtitle), composer, length, bars.
   - Drop zone.
   - Details panel: title, composer combo box, tags, hand channels, meter + override, Play.
   - Keep all milestone 4 behavior (editing, bulk export, Safari protections).

## Tests

- Unit: registry (every setting has a valid default within limits, groups derived correctly), reset / reset group / undo, settings migration, tempo range (constant, changing, single-event tempo maps), composer suggestions (case-insensitive substring, exact-match detection, sorted list with counts), contrast-based text color on primary.
- Playwright:
  - change a setting → reset icon becomes active → reset restores the default;
  - section reset and tab reset with Undo;
  - theme color and preset change persist across reload;
  - open the picker, choose a song, load it;
  - sidebar opens, and a change applies live;
  - Esc and focus handling in dialogs;
  - no console errors.
- Visual screenshots (`npm run test:visual`): player, player with sidebar, settings window (Audio and Appearance tabs), picker, library. At 1280×720 and 1024×768 (iPad landscape), with the default theme and Ember. Check them against `docs/design/m6/` yourself.
- Reduced motion: transitions become fades.

# Milestone 5 — Visual clarity

Read CLAUDE.md, docs/brief.md and docs/roadmap.md first, then plan the following. Work on a branch (`feat/m5-visual-clarity`), not `main`.

## Goal

Notes, lanes and keys currently blend together. This milestone adds separation and a more physical look: 3D note heads, lifted black-key-lane notes with a contact shadow, shaded black-key lanes, simple lighting, configurable key dimensions with chamfered/rounded edges, animated key presses, velocity-scaled effects, and better render quality. Every item is a setting with the defaults below (tuned in a sketch session).

## Items and defaults

Units: world units, 1 = one white-key width (23.5 mm).

1. **3D note heads.** Heads become raised blocks with the same footprint as today (lane width × 1/64 note). Height **0.35**, **rounded edges on**. Sustains stay flat. Requirement: the edge rounding/bevel stays the same size in world units regardless of note length, tempo or look-ahead — it must not stretch with the head. Black-lane heads draw above white-lane heads.
2. **Black-key-lane notes lifted.** Notes in black-key lanes (heads and sustains) float at a lift that **defaults to matching the black-key height** (so they meet the raised key tops exactly at the now line); the setting can switch to a manual value 0–0.8.
3. **Contact shadow.** A soft shadow under black-lane notes, falling on the highway and on neighboring white-lane notes. Strength **45%**, soft edge. A faked shadow (e.g. blurred quads or a shader term) — no shadow maps.
4. **Black-key lane shading.** Black-key lanes on the highway are darker than white-key lanes. **On**, strength **22%**.
5. **Simple lighting.** One key light + ambient so 3D shapes read: lighter top faces, darker front/side faces, highlights on chamfers/rounded edges. Applies to keys and note heads. No shadow maps, no post-processing (that's milestone 9).
6. **Keyboard dimensions** (defaults keep the grand-piano proportions): key thickness **0.6**, gap between keys **0.06**, black key length **63%** of white, black key height **0.45**. "Reset to grand piano". Requirement: **lanes never move** — gaps shrink the key bodies within their lane positions, so notes still meet key centers.
7. **Key edge profile:** **none / chamfer / rounded**, size setting. Default **chamfer, 0.04** (≈1 mm) on all edges of white and black keys.
8. **Animated keys.** Keys pivot down at their back edge on note-on and return on note-off (quick press, slightly slower release; no overshoot). **On**, press depth **0.22** at the front edge. A pressed key's color overlay moves with it.
9. **Velocity-scaled effects.** Spark burst size/count and held-glow size scale with note velocity: **on**, size **0.6×** at velocity 0 → **1.7×** at 127 (linear). Option for uniform size.
10. **Render quality.** First investigate why the current image looks soft/grainy (pixel-ratio cap, missing MSAA on the render target, thin-line aliasing, texture filtering) and fix the defaults. Then settings: render scale (**auto** = device pixel ratio, or 0.5×–2×), max pixel ratio (default 2), anti-aliasing (off / MSAA / FXAA or SMAA — use what ships with `three`, no new dependencies). Show internal resolution and average frame time next to these settings.

## Tests

- Unit (pure logic): key layout with gap / black length / height (lanes unchanged by gap; keys inside their lanes); lift default follows black-key height; velocity → effect scale; press animation curve; settings v1 → v2 migration and clamping.
- Playwright: settings changes apply and persist; no console errors.
- **Visual review screenshots** (`npm run test:visual`), Minuet and a synthetic fixture with neighboring sharp/natural notes sounding together:
  - zoomed (negative distance offset) at default settings, at tilt 30°, 45°, 70°;
  - each item toggled off vs. on (heads flat vs. 3D, lift + shadow off vs. on, lane shading off vs. on, edge profile none / chamfer / rounded, keys pressed);
  - render quality before vs. after the fix, same view.
  Check them yourself: lanes meet key centers at all tilts and gaps; lifted notes meet black key tops; bevels don't stretch on long or short heads; chamfer highlights visible but subtle.
- Performance: average frame time on the Canon before and after (same machine), at default and highest render quality.

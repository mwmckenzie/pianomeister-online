# Milestone 7.6 — Now playing & play tracking

Read CLAUDE.md, docs/brief.md and docs/roadmap.md first, then plan the following. Work on a branch (`feat/m7-6-now-playing`), not `main`. This revises parts of milestone 7 (brief decisions on loading, temporary changes, plays and stats) — update those decisions rather than adding contradicting ones.

## Goal

The player always shows exactly what you are practising, and stats count plays the way a player thinks about them. Song stats are tracked on their own, so they stay correct when bookmarks are edited or deleted. This must land before the Welcome & stats milestone, which builds on these numbers.

## Decisions

### Now playing (the line below the composer)

1. **It reflects the current setup, live** — song, loop range (or none), tempo, right/left hand modes, pre-roll beats and mode, metronome mode — not "the last thing loaded".
2. **Matches a bookmark exactly** (`sameBookmarkSettings`): show a bookmark icon (sized to the text, secondary colour) and the bookmark's name, in the secondary colour. Changing settings so they match an existing bookmark **adopts** it: it counts as playing that bookmark from then on (no jump, no reload, no toast).
3. **Matches Full song exactly**: no loop, 100 %, and hand modes, pre-roll and metronome equal to the global settings (Audio and Practice tabs). Show the bookmark icon and "Full song", in the secondary colour, like any bookmark.
4. **Matches nothing**: plain dim text, no icon, the setup written exactly like a bookmark's auto name: "Bars 20–35 · 100% · both hands · quiet pre-roll 2", or with no loop "Full song · 85% · left muted · pre-roll 2".
5. **The temporary-changes dot and the "Temporary for ⟨bookmark⟩" notes go away** — the line itself now says what's playing. The session layer stays as it is: player-side changes never write to a bookmark or (while a bookmark was the last thing loaded) to the global settings.
6. **Back to the bookmark:** the loop popover keeps a button to return to the last loaded bookmark ("Back to ⟨name⟩"), shown only while the setup differs from it.

### What counts as a play

7. **A play is a start, not a finish.** Count one play when playback starts:
   - after loading a song or bookmark,
   - after Stop / Back to start / the song ending (playback starts from the parked start position),
   - at every loop restart (each wrap counts).
     Resuming after a pause is **not** a new play. Seeking while paused and then resuming is a resume, not a play. The old "complete pass" rule goes away.
8. **Practice time** is unchanged: all time the transport is playing (including pre-roll).

### Attribution

9. **Every play and every second always counts for the song.** Song stats (plays, time, last practiced, chart) come from all of the song's records — never summed from bookmarks — so editing or deleting bookmarks never changes a song's totals.
10. **A bookmark (or Full song) only gets the plays and time made while the setup matches it exactly** (decision 2/3). Anything else is recorded for the song with no bookmark ("other setups"). A setup change mid-play already splits the record (milestone 7); a split into a matching setup attributes from that moment on.
11. **Deleting a bookmark keeps its records** (they still count for the song). Deleting an upload with "also delete practice stats" still removes them all.
12. **Share of song time** = bookmark (or Full song) time ÷ the song's total time, which now includes other setups.
13. **Existing play records:** keep them; `plays` for an old record = its `passes`. Records keep their bookmark attribution as recorded.

### Additions (agreed when planning)

14. **The Revert to bookmark command (decision 89) becomes "Back to bookmark"**, matching the loop popover's "Back to ⟨name⟩" button; it does nothing when the setup already matches the last loaded entry. With Full song last loaded, the button reads "Back to Full song" (loop off, 100%).
15. **The Practice tab's "The defaults for Full song…" note stays** (decision 68); only the "Temporary for ⟨bookmark⟩" notes and the dot go.
16. **The now-playing hover hint uses the key in effect** for Save as bookmark ("Doesn't match a bookmark · press ⟨key⟩ to save it").
17. **No special cases:** loop nudges, tempo keys, the metronome toggle and Back to bookmark all just change the setup; the now-playing line and attribution follow from it.
18. **Adoption changes the now-playing line and attribution only.** The last loaded entry stays as it is: it's what Back to returns to, it decides whether edits are temporary or global, and it's what Resume reopens.
19. **A committed loop change's jump to the new loop start counts as a start** (it restarts a section from its beginning): while playing it counts at once; while paused or stopped it arms a play that counts on the next Play. Nudges settle first, so one jump is one play. Play after Stop and a timeline click is a start too.
20. **Records keep the full setup** — tempo %, loop, hand modes, pre-roll beats and mode, metronome mode — so 7.7 can group other setups; the old `temporary` flag goes.

## Screens

- **Player HUD:** the now-playing line per decisions 1–6. Remove the dot. Hover on a non-matching line shows "Doesn't match a bookmark · press B to save it".
- **Picker:** song stats from the song's own records; in the middle column, under the selected entry's stats, a small line "Other setups: 12 plays · 18 min" when the song has any.
- **Bookmark manager, library:** song and bookmark numbers per decisions 9–12 (no visual change).

## Core and data

- `nowPlaying(setup, bookmarks, globals)` → `{ kind: 'bookmark' | 'fullSong' | 'custom', bookmark?, label }` (pure, tested).
- `PlayRecorder`: replace pass counting with start counting (decision 7); attribution per decision 10.
- Stats: song totals from all records; bookmark totals from matching records; "other setups" totals.
- Dexie step only if a field changes shape (`passes` → `plays`); keep it schema-only plus that deterministic copy.

## Tests

- **Unit:** `nowPlaying` for bookmark / Full song / custom, adoption when settings come to match; label text identical to auto names; `PlayRecorder` start counting (load, stop, song end, each wrap, pause/resume not counted, seek-while-paused not counted); attribution when matching / not matching / switching mid-play; song totals unchanged after deleting a bookmark; record migration.
- **E2e:** load bookmark → icon + name; change tempo → plain summary text, no icon; change it back → icon again; tweak settings to equal another bookmark → that bookmark shows and gets the plays; three loop wraps = three plays; pause/resume = one play; delete a bookmark → song plays and time unchanged; picker "Other setups" line.
- **Visual:** HUD with a bookmark, with Full song, with a custom setup; picker with an "Other setups" line.
